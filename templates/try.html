Discovery Prompt
Build a taxonomy of the subjects I have discussed in the conversation history you can actually access. Output only domain, subdomain, topic, and subtopic names. TASK Extract every Domain, Subdomain, Topic, and Subtopic supported by my own messages, and return only the hierarchy as a single JSON object. DEFINITIONS - Domain: a broad field (e.g., Software Engineering, Finance, Career, Health). - Subdomain: a specialization inside a domain (e.g., Backend Engineering inside Software Engineering). - Topic: a specific subject I asked about or worked on within a subdomain. - Subtopic: a specific question, concept, tool, decision, or problem inside a topic. RULES 1. Cover all subjects I discussed, including casual and one-off topics. Use concise topic labels only. 2. Use my own messages to identify subjects. Do not add topics based only on chatbot replies, general knowledge, or inferred interests. 3. Merge near-duplicate topics, but keep distinct questions as separate subtopics. 4. Do not analyze or describe my personality, background, profile, biography, preferences, or experiences. Return subject names only. 5. Do not include metadata, evidence notes, dates, periods, frequency, confidence, coverage notes, descriptions, or any other fields. 6. Use only the keys shown in the output format: "domains", "domain", "subdomains", "subdomain", "topics", "topic", and "subtopics". Subtopics must be an array of strings. 7. Use only history you can actually access. Do not invent missing subjects or claim access to unavailable chats. If no subjects can be identified, return {"domains": []}. 8. Do not include personal identifiers (passwords, API keys, phone numbers, addresses). 9. Output ONLY valid JSON. No markdown, commentary, or additional sections. OUTPUT FORMAT { "domains": [ { "domain": "Domain name", "subdomains": [ { "subdomain": "Subdomain name", "topics": [ { "topic": "Topic name", "subtopics": [ "Subtopic 1", "Subtopic 2" ] } ] } ] } ] } Before finalizing, check that every supported subject sits under the correct domain and subdomain, that only the allowed hierarchy keys and subject labels appear, and that the JSON is valid.
